# 6개 사례용 구조 평가 질문 설계안 (초안 · 승인 전)

작성 2026-10-14 · 상태: **제품 오너 승인 (2026-10-14), 구현됨**

## 1. 목적과 원칙

현재 원래 조직·직무 평가(FIFWM, 원래 설문 Q18–22)는 퇴사·유지, 산업 전환, 역할 상향·하향 3개 사례에만 적용됩니다. 나머지 6개 사례(창업, 학위, 해외 이주, 번아웃, 가족 제약, 일반 재구성)는 항상 "미평가"입니다. 이 설계안은 6개 사례에도 같은 다섯 요소로 구조를 평가하는 질문을 제안합니다.

지키는 것(변경 없음):
- 다섯 요소와 고객 표현은 그대로입니다: Formal 기회의 조건 · Informal 연결 가능성 · Framework 구조 적합성 · Workflow 실행 현실성 · Market-Policy 버틸 수 있는가.
- 각 질문은 승인된 세 선택지와 0 / 1 / 2 점수를 씁니다. 원래 표와 같은 형식입니다.
- "아직 모름"과 "해당 없음"은 점수를 매기지 않고 미평가로 둡니다. 0점으로 바꾸지 않습니다.
- Posture 공식, 8/1 경계, guardrail, Safety Margin은 바꾸지 않습니다.
- 원래 3개 사례의 질문과 점수표도 바꾸지 않습니다.

새로 생기는 것:
- 사례별 질문 세트입니다. 원래 질문 번호 Q18–22와 섞지 않고 **"사례 맞춤 구조 평가"**라는 별도 출처로 기록합니다. 화면과 보고서에도 "원래 조직 평가"와 구분해 표시합니다.
- 질문은 구체적인 대상이 있을 때만 엽니다. 예를 들어 학위는 기관·과정명, 해외 이주는 목적지를 고객이 확인해야 합니다. 대상이 없으면 지금처럼 미평가입니다.

## 3. 영향과 확인할 점

- **결과가 달라집니다.** 지금 6개 사례는 FIFWM이 없어서 중립값 1로 계산됩니다. 답이 들어오면 평균값이 바뀌고, 구조 판단도 달라질 수 있습니다. 구현 전에 사례별로 대표 입력 3개씩, 총 18개를 수정 전후로 계산해 판단이 어떻게 바뀌는지 표로 보고드리겠습니다.
- **원래 Python 엔진과의 관계.** 원래 엔진(src/scoring/fifwm.py)은 Q18–22만 압니다. 새 질문은 V2 전용 확장으로 두고 엔진은 바꾸지 않습니다. 엔진에도 넣을지는 별도로 결정해 주세요.
- **고객 화면 부담.** 사례마다 질문 5개가 4단계(실행 준비도)에 추가됩니다. 지금처럼 "대상이 있나요?"에 "있음"을 고를 때만 보입니다.
- **번아웃의 대상.** 머무는 경우와 옮기는 경우에 따라 대상 일터가 다릅니다. 질문에 "판단하려는 일터 기준"이라는 안내가 필요합니다.
