# allofmycareer V2 문구 가이드 (한국어 · English)

기준일: 2026-10-15. 오너 피드백("시험 범위를 줄여야 위험이 줄어든다"처럼 이직 맥락에 맞지 않는 단어, 부자연스러운 번역투)과 경쟁사 벤치마킹(CareerLeader, Hogan, Lightcast, Fuel50, Phenom, CareerExplorer, Careershifters)을 반영했다.

프레임워크, 점수, 판단 규칙은 바꾸지 않는다. 바꾸는 것은 고객이 읽는 단어와 문장뿐이다.

## 1. 벤치마크에서 가져온 문장 원칙

| 출처 | 원칙 | 적용 |
|---|---|---|
| CareerLeader | 2인칭으로 쓴 쉬운 해설. 해석 뒤에는 확인 질문을 붙인다 | "당신은 ~한 사람"이 아니라 "지금 조건에서는 ~입니다. 확인할 것: ~?" |
| Hogan | 조건부·양면 해석 | "~할 때는 도움이 되지만, ~라면 약해집니다" |
| Lightcast | 근거의 범위를 정확히 쓴다 | "이 자료는 ~를 보여 줍니다. ~까지는 보여 주지 않습니다" |
| Fuel50·Phenom | 경로·격차를 행동 단위로 쓴다 | "다음 단계: ~ / 필요한 것: ~" |
| CareerExplorer | 전문용어 대신 사용자의 질문으로 쓴다 | 이름은 유지하고, 그 아래에 질문 한 줄을 붙인다 |
| Careershifters | 작은 실천과 대화로 확인한다 | "작게 확인해 보기", "실무자와 대화해 확인하기" |

## 2. 한국어 문장 규칙

1. 존댓말 '~합니다 / ~하세요'로 통일한다. 한 문장에는 한 가지 생각만 담고, 되도록 60자 안팎으로 쓴다.
2. 괄호 안에 괄호를 넣지 않는다. 인용은 ‘ ’를 한 번만 쓴다.
3. 같은 문장을 한 단락 안에서 반복하지 않는다.
4. 번역투를 쓰지 않는다. '~에 대한', '~를 통해', '~하는 것이 필요합니다', '~가능해집니다' 대신 바로 동사로 쓴다.
5. 조사는 앞말에 맞춘다(`withKoreanParticle`). '(으)로', '을(를)' 같은 병기는 쓰지 않는다.
6. 고객이 고른 '기타'는 문장 안에 넣지 않는다.

## 4. 화면별 톤

- **설문**: 질문은 고객이 스스로에게 묻는 말투로 쓴다("결정을 6~12개월 미루면 어떻게 될 것 같나요?"). 보기는 서로 겹치지 않는 하나의 상황으로 쓴다. 그룹 제목은 명사형 짧은 구로 쓴다("새 기회 때문에", "지금 자리의 한계 때문에").
- **대시보드**: 결론 한 줄 → 이유 한두 개 → 할 일 하나 순서로 쓴다. 긴 단락을 쓰지 않는다.
- **리포트**: 같은 판단을 더 길게 설명하되, 섹션마다 '무엇을 확인했고, 무엇을 아직 모르며, 무엇을 하면 되는가'를 지킨다.
